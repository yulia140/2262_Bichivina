### Задание 1 **(2)**
*Рассмотрим следующую программу.*
```
d = {'sep': ',' , 'end': '\n'}
l = ['Утопия', 14, 'Вселенная', 25]
print (l, d)
print (*l, d)
print (*l, *d)
print (*l, **d)
```
*Объясните результаты ее работы.*

*При устном ответе на вопросы вам потребуется рассказать, что такое "Утопия 14" и "Вселенная 25".*
В программе объявлены словарь d с ключами sep и end и список l из четырёх элементов. Далее выполняются четыре вызова функции print, различающиеся способом передачи аргументов.

В первом вызове print(l, d) оба объекта передаются как есть, без распаковки. Функция выводит строковые представления списка и словаря, разделяя их пробелом.

Во втором вызове print(*l, d) оператор * применяется к списку l. Этот оператор распаковывает итерируемую последовательность: каждый элемент списка становится отдельным позиционным аргументом функции print. Словарь d при этом остаётся одним аргументом и выводится в виде словаря.

В третьем вызове print(*l, *d) оператор * применяется и к списку, и к словарю. При распаковке словаря итерация происходит по его ключам, поэтому в качестве позиционных аргументов передаются ключи sep и end, а не значения. В результате выводятся элементы списка и ключи словаря.

В четвёртом вызове print(*l, **d) используется оператор **, который распаковывает словарь в именованные аргументы. Ключи словаря должны совпадать с именами параметров функции. В данном случае ключи sep и end соответствуют параметрам функции print, управляющим разделителем и завершающим символом. Поэтому элементы списка выводятся через запятую, а в конце строки добавляется перевод строки.

### Задание 2 **(2)**
*Напишите функцию* **sublist** для решения следующей задачи.*

*На вход функции поступает список или кортеж и набор номеров позиций.
Функция должна составить и вернуть список из элементов, которые
находятся на этих позициях. Примеры работы приводятся ниже. Работа функции должна строго им соответствовать.*

```
>>> lst = [ 'Anna', 'Barbara', 'Clara', 'Diana', 'Eva', 'Flora']
>>> sublist(lst, 0, 2, 5)
['Anna', 'Clara', 'Flora']
>>> sublist (lst)
[]
>>> sublist(lst, 0, 1, 2, 3, 4, 5)
['Anna', 'Barbara', 'Clara', 'Diana', 'Eva', 'Flora']
```
Решение 

```
def sublist(lst, *args):
    res =[]
    for index in args:
        res.append(lst[index])
    return res
lst = [ 'Anna', 'Barbara', 'Clara', 'Diana', 'Eva', 'Flora']
print(sublist(lst, 0, 2, 5))
print(sublist (lst))
print (sublist(lst, 0, 1, 2, 3, 4, 5))
```


### Задание 6 **(2)**

*Запишите генератор в форме функции, который будет создавать
последовательность по следующему правилу.*

* *Если текущее число x в последовательности четное, то следующее число равно x/2.*
* *Иначе следующее число равно 3x + 1.* 

*Последовательность начинается с заданного числа n и заканчивается единицей.*

*Далее приведен пример работы генератора.*
```
>>> print (*gen(7))
7 22 11 34 17 52 26 13 40 20 10 5 16 8 4 2 1
```

Решение

```
def gen(x):
    yield x
    while x != 1:
        if x%2 == 0:
           x//=2
        else:
            x = 3 * x +1
        yield x
```

*Какие из указанных функций и методов Python соответствуют определению чистых функций?
В случае отрицательного ответа требуется дать пояснение.*

* **file.readline|** — *чтение строки из файла.*
* **len** — *определение длины строки или количества элементов в контейнере.*
* **list.append** — *добавление в список нового элемента.*
* **sum** — *нахождение суммы.*
* **sorted** — *построение сортированного списка.*
* **list.sort** — *сортировка списка.*
* **random.randint** — *генерация случайного целого числа.*
* *Разворот списка.*
```
def rev(x):
    return x[::-1]
```
* *Выбор нескольких элементов из хвоста списка.*
```
tail_len = 3
def tail(x):
    return x[-tail_len:]
```

чистая функция при одинаковых аргументах всегда возвращает одинаковый результат и не имеет побочных эффектов (не изменяет внешние объекты, не пишет в файлы, не использует случайность и глобальное состояние).

Разбор:

file.readline — не чистая. Изменяет позицию чтения в файле (побочный эффект), результат зависит от состояния файла.

len — чистая. Только читает объект, результат детерминирован.

rev(x) — чистая. Возвращает новый срез, исходный объект не изменяется.

###  Задание 11 **(2)**
*Рассмотрите следующую функцию.*
```
def toint(fun):
    def wrapper(*args):
        return fun(*map(int, args))
    return wrapper
```
*Что передается в функцию* **toint**? *Что возвращает эта функция?*
*Что делает функция* **wrapper**?
*Придумайте несколько примеров использования* **toint**.

Что передаётся в toint? Функция fun — любой вызываемый объект, который нужно обернуть.

Что возвращает toint? Новую функцию wrapper (замыкание), сохраняющую fun в своей среде.

Что делает wrapper? Принимает произвольное число позиционных аргументов (*args), преобразует каждый аргумент в целое число с помощью map(int, args), вызывает исходную функцию fun с этими целыми аргументами и возвращает её результат.

Примеры использования:

```
def add(a, b):
    return a + b

add_int = toint(add)
print(add_int('2', '3'))   # 5

def mul(a, b, c):
    return a * b * c

mul_int = toint(mul)
print(mul_int('2', 3, '4'))  # 24
```
